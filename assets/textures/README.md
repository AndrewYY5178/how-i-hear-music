# Newsprint material preview

`newsprint-fibres-v1.png` was generated with the built-in imagegen tool on 2026-09-08. Local review only; not yet published. The Paper theme uses a single 768px tile at 42% multiply opacity. Chromatic is unchanged. Actual Home screenshots reviewed at 390 and 1440px.

Generation prompt: Square flatbed scan of clean unprinted newsprint, macro texture filling the image. Neutral warm offwhite base, clearly visible randomly intertwined short wood-pulp fibres, irregular small grey flecks and porous roughness with gentle uneven paper formation. Fine organic structure at several scales, not uniform digital noise. Even flat lighting, consistent edge density for tiling, no shadow or vignette, objects, text, ink, stains, creases, torn edges or yellow parchment. Enough fibre contrast for soft multiplication over #e7dfcf. Photorealistic material, not geometric mesh or linen.

The texture is an absolute, document-height pseudo-element anchored to the positioned body, with scroll background attachment. It moves with document content rather than staying fixed to the viewport; pointer events remain disabled. Chromatic keeps this layer invisible.

Before production: optimize asset weight, check offline caching and review tile repetition across long pages. This candidate is intentionally more visible than the previous fine-noise treatment.
